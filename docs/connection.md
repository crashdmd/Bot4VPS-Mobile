# Подключение мобильного приложения

Bot4VPS Mobile подключается к серверу через отдельный HTTPS Mobile API. Web-панель используется для первоначальной настройки API, создания привязки и управления подключёнными телефонами.

Mobile API выключен по умолчанию. После включения он работает независимо от доступности Web-панели. Оба интерфейса используют общие данные мониторинга, настройки Telegram и очередь задач.

Для работы требуется Bot4VPS 7.0 или новее.

## 1. Включение Mobile API

Откройте Web-панель и перейдите в **Настройки → Мобильное приложение**.

Для подключения необходимо задать три параметра:

- **Порт для сервиса** — порт, на котором Bot4VPS будет принимать HTTPS-запросы приложения. Например, `8444`. Он должен отличаться от порта Web-панели.
- **Адрес для приложения** — IP-адрес или домен, доступный с телефона. Можно указать адрес с `https://` или без него. Если порт не указан, Web-панель подставит порт сервиса.
- **Разрешить подключение** — включает или выключает Mobile API с сохранёнными настройками.

Если внешний порт отличается от внутреннего, укажите его в адресе приложения. Например, при пробросе `9444 → 8444` используйте `https://api.example.com:9444`.

Порядок первоначальной настройки:

1. Укажите порт и адрес приложения.
2. Нажмите **«Сохранить подключение»**.
3. Включите **«Разрешить подключение»**.

При изменении адреса или порта сохранение перезапускает работающий API. Если API выключен, новые параметры просто сохраняются.

Статус API отображается в настройках и обновляется автоматически. При ошибках форма показывает сообщение, а переключатель отражает фактическое состояние службы.

## 2. Сетевой доступ

Mobile API использует отдельный HTTPS-порт. Web-панель и API могут иметь разные адреса и порты.

**В локальной сети**

Для подключения достаточно локального IP-адреса сервера. Например:

- Web-панель: `http://192.168.1.100:8080`
- Mobile API: `https://192.168.1.100:8444`

Домен, белый IP, Let's Encrypt и установка собственного CA на телефон не требуются. При привязке приложение получает отпечаток ключа сервера и использует его для проверки соединения.

Локальный IP доступен только из соответствующей сети или через VPN, обеспечивающий доступ к ней.

**Доступ из интернета**

Для подключения через интернет потребуется внешний адрес сервера и проброс TCP-порта API на машину с Bot4VPS.

Например:

- внешний порт: `9444`;
- внутренний порт: `8444`;
- адрес в приложении: `https://api.example.com:9444`.

Открывать Web-панель для работы уже привязанного приложения необязательно. После привязки можно оставить доступным только HTTPS-порт Mobile API, а Web-панель закрыть внешним файрволом.

Для первоначальной и повторной привязки, а также отзыва доступа можно использовать локальные команды CLI.

**Важное замечание:** если телефон использует мобильный интернет, локальный адрес вроде `192.168.1.100` обычно недоступен. Для такого подключения используйте VPN или внешний адрес с пробросом порта.

### Файрвол сервера

При включении Mobile API Bot4VPS автоматически открывает TCP-порт API в локальном файрволе. При выключении правило удаляется. При смене порта правило переносится на новый порт.

Поддерживаются:
- UFW;
- firewalld;
- управляемая входящая цепочка собственной таблицы `inet bot4vps`.

Существующие правила других сервисов сохраняются. Для вручную настроенного iptables или сторонних цепочек nftables автоматическое применение не гарантируется. Если входящие соединения уже разрешены, дополнительное правило не требуется.

Правила управляются отдельным root-помощником. Основной процесс Bot4VPS продолжает работать от системного пользователя `bot4vps`.

Если автоматическое изменение файрвола невозможно, настройте доступ вручную.

## 3. Привязка телефона

После включения Mobile API откройте блок **«Добавить телефон»** в настройках мобильного приложения.

Доступны два способа привязки:

**Через QR-код**
1. В Web-панели нажмите **«Создать QR-код»**.
2. В приложении выберите **«Сканировать QR»**.
3. Разрешите доступ к камере и отсканируйте код.

**Через текстовый код**
1. В Web-панели нажмите **«Получить код»**.
2. В приложении выберите **«Ввести код»**.
3. Введите полученный код.

Оба способа содержат одинаковые данные: адрес API, одноразовый секрет и отпечаток открытого ключа сервера. Сканирование QR выполняется непосредственно на телефоне, без внешних сервисов.

Код привязки действует 10 минут и используется только один раз — при первой успешной регистрации телефона. Если код истёк или привязка не удалась, создайте новый.

После успешной регистрации телефон появится в списке **«Привязанные устройства»**.

### Управление привязанными устройствами

В Web-панели отображается список подключённых телефонов.

При отзыве доступа:
- телефон теряет возможность подключаться к API;
- его активные потоки и терминальные соединения завершаются;
- для повторного подключения потребуется новая привязка.

Если приложение потеряло связь с сервером, это само по себе не означает, что привязка утрачена. Переустанавливать приложение из-за обычной сетевой ошибки не требуется.

## 4. Работа приложения

При запуске приложение подключается к сохранённому адресу панели. Если подключение не удалось за 10 секунд, появляется сообщение о сетевой ошибке и возможность повторить попытку или изменить адрес.

Для подключения к другой установке Bot4VPS отсканируйте её QR-код или введите полный код привязки.

Один только адрес сервера не предоставляет доступ: для подключения требуется действующая привязка телефона.

При смене адреса или порта прежней установки может потребоваться новая привязка, поскольку она связана с HTTPS-адресом и портом API.

Сетевая ошибка не удаляет привязку и локальный PIN-код.

## 5. Web-панель и авторизация

Web-панель и Mobile API используют разные механизмы доступа.

Web-панель отвечает за первоначальную настройку, создание привязок и управление устройствами. Mobile API проверяет криптографический ключ зарегистрированного телефона.

Поэтому после привязки телефона Web-логин и Web-2FA при обычном входе в мобильное приложение не требуются.

Web-панель может работать по HTTP в доверенной локальной сети. Для внешнего доступа к ней используйте HTTPS или VPN.

Если Web-авторизация выключена, управление привязками через панель ограничивается доверенной локальной сетью. При использовании обратного прокси с выключенной авторизацией дополнительно ограничьте доступ к панели на уровне сети: сервер видит адрес прокси, а не реальный адрес посетителя.

Для доверенного DNS-имени в этом режиме можно явно задать адрес Web-панели в окружении службы:

```ini
Environment=BOT4VPS_MOBILE_API_WEB_ORIGIN=http://panel.example.com
```

Замените `panel.example.com` своим адресом. После изменения выполните:

```bash
systemctl daemon-reload
systemctl restart bot4vps
```

Эта настройка нужна только при выключенной Web-авторизации и обращении к панели по доверенному DNS-имени. Она не включает HTTPS и не заменяет сетевую защиту.

## 6. Выключение Mobile API

Чтобы отключить мобильный доступ:

1. Откройте **Настройки → Мобильное приложение**.
2. Выключите **«Разрешить подключение»**.

API перестанет принимать запросы, а созданное для него правило файрвола будет удалено. Ключи сервера и записи привязанных устройств сохраняются.

Повторное включение не требует повторной регистрации телефонов, если адрес и ключ сервера не изменились.

## 7. Управление через CLI

Если Web-панель недоступна или закрыта извне, привязками можно управлять из командной строки.

Команды выполняются из каталога установки Bot4VPS:

```bash
venv/bin/python -m ui.web._internal.device_access.access pair --name "Мой телефон"

venv/bin/python -m ui.web._internal.device_access.access list

venv/bin/python -m ui.web._internal.device_access.access revoke ID_ТЕЛЕФОНА
```

- `pair` — создать код для привязки нового телефона;
- `list` — показать зарегистрированные устройства;
- `revoke` — отозвать доступ конкретного телефона.

Вместо `ID_ТЕЛЕФОНА` укажите идентификатор устройства из списка. Код привязки является одноразовым секретом — передавайте его только владельцу телефона.
