# Bot4VPS Mobile 1.6.0

- Проверка доставки Telegram запускается из настроек работающего бота: успех — всплывающее сообщение, ошибка — диалог с кнопкой «Ок».
- После сетевой ошибки проверка обновлений приложения доступна повторно; суточный интервал считается от успешной проверки.
- При удалении привязки удаляется также сохранённый секрет операций этой панели.
- На экранах сервисов убран список групп, фильтры установки сохранены.
- В пинге и SSL сводка находится под временем последней проверки. Сохранённый список открывается кнопкой «Результаты последней проверки»; новая проверка показывает актуальные данные. Сортировка пинга и срока сертификатов доступна в шапке списка.
- Обновлены OkHttp 4.12.1 и совместимый комплект сборки Gradle 8.14.7 / Kotlin 2.2.20 / Android Gradle Plugin 8.10.1 / Hilt 2.57.1.

## Bot4VPS Mobile 1.5.0

- Источник APK и метаданных перенесён в отдельный репозиторий Bot4VPS-Mobile. Новая сборка с тем же именем версии может обновляться при большем versionCode.

- Привязка телефона по QR и вход по его ключу без повторного Web-логина. Подключение по HTTPS к локальному IP без домена.
- При запуске виден адрес панели; «Изменить адрес» и «Подключиться к другой панели» доступны сразу. Через 10 секунд без ответа появляется подсказка о сети, VPN, адресе и порте. Сетевая ошибка не удаляет привязку.
- Просмотр мастер-ключа через PIN-код или биометрию; без защиты приложения — через пароль и второй фактор. Ключ скрывается при сворачивании и через 30 секунд.
- Автоблокировка после 30 секунд в фоне. Тема приложения сохраняется на телефоне отдельно от Web.
- Пинг серверов на «Обзоре», общий экран проверок пинга и SSL-сертификатов с сохранением результатов.
- SSH-терминал сохраняет соединение и вывод до пяти минут при уходе с экрана; нижние вкладки скрыты.
- Очистка журнала событий и истории задач вынесена в шапки экранов; переход между ними занимает всю ширину и содержит подсказку.


## Установка

Mobile 1.1.3 не подключается к Bot4VPS 7.0. Для работы с этой версией панели установите Mobile 1.6.0. При переходе с Mobile 1.1.3 нужна переустановка из-за смены подписи. Сохраните доступ к Web для новой привязки, удалите прежнее приложение и установите 1.6.0. Данные и серверы Bot4VPS сохраняются; локальные настройки телефона потребуется настроить заново.

[Подключение телефона](docs/connection.md) · [Сборка и подпись](docs/development.md).
