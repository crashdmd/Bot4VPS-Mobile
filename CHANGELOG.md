# Bot4VPS Mobile 1.8.0

- Логин и пароль 3x-ui меняются в одном окне, как в Bot4VPS 7.2. Есть генерация пароля и выбор перезапуска. Проверяются ограничения сервера, включая 72 байта UTF-8; при ошибке введённые поля сохраняются в форме.
- Неизвестное состояние сервиса показывается как «Не удалось проверить» с причиной и повторной проверкой. Оно не попадает в фильтр «Не установлен» и не разрешает установку или изменение по старым данным.
- Выбранный SSH-ключ можно загрузить под другим именем при конфликте. Используемый ключ нельзя удалить или заменить.
- После ответа «Задача не найдена» автоматический опрос прекращается; итог остаётся неизвестным. Доступны список задач, проверка сервиса и закрытие наблюдения. Временная потеря сети не считается исчезновением задачи.
- После успешной команды с ошибкой сверки состояния показано предупреждение: повторять выполненную команду не требуется. Ручная синхронизация учитывает ошибки вложенного состояния.
- В аудите отображается имя телефона. Карточка сервера показывает отдельный публичный IP SSL с копированием. Подсказки сертификатов объясняют включение SSL-мониторинга фактического домена/IP, Backup — копирование доступных источников без sudo.

Обновление сохраняет данные приложения и привязки телефонов. Новая форма
учётных данных 3x-ui и новые правила SSH-ключей требуют Bot4VPS 7.2.

## Bot4VPS Mobile 1.7.8

- **Authenticator:** локальные TOTP-коды для Bot4VPS и сторонних сервисов, добавление через QR или ключ настройки, поиск по аккаунтам и индикатор времени действия кода. Доступ сохраняется без сети, подключённой панели и после отзыва доступа.
- **Вход и подтверждения:** вход в Web по QR и всплывающие запросы безопасности с адресом панели, описанием действия, пользователем, IP и временем. Ожидающие запросы всех подключённых панелей доступны из любого раздела приложения и сопровождаются уведомлениями на телефоне.
- **Основной телефон:** роль устройства и её возможности отображаются в настройках безопасности. Основной телефон подтверждает чувствительные действия и получает TOTP панели; ему доступны список подключённых телефонов, отзыв доступа и добавление устройств через QR или ручной код. Имя подключаемого телефона передаётся автоматически.
- **Несколько панелей:** сохранённые подключения можно переключать. После отвязки сервис удаляется из выбора с уведомлением; единственный оставшийся открывается автоматически, при нескольких предлагается выбор. Без подключённых панелей первым открывается Authenticator.
- **Смена адреса:** новый адрес Mobile API можно отсканировать из QR или ввести вручную. Подтверждённая смена адреса или порта сохраняет существующую привязку и данные приложения; при ручном вводе используется HTTPS по умолчанию.
- **Удобство работы:** обновлены навигация, диалоги и настройки безопасности. Фильтры серверов размещены в одну строку; выбранные фильтры и видимость IP и доменов сохраняются отдельно для списков. Биометрическую разблокировку можно включить в дополнение к PIN.

Обновление устанавливается поверх 1.6.0 с сохранением данных приложения.
Для новых функций безопасности нужна актуальная панель Bot4VPS 7.1;
локальный Authenticator работает независимо от неё.

## Bot4VPS Mobile 1.6.0

- Проверка доставки Telegram запускается из настроек работающего бота: успех — всплывающее сообщение, ошибка — диалог с кнопкой «Ок».
- После сетевой ошибки проверка обновлений приложения доступна повторно; суточный интервал считается от успешной проверки.
- При удалении привязки удаляется также сохранённый секрет операций этой панели.
- На экранах сервисов убран список групп, фильтры установки сохранены.
- В пинге и SSL сводка находится под временем последней проверки. Сохранённый список открывается кнопкой «Результаты последней проверки»; новая проверка показывает актуальные данные. Сортировка пинга и срока сертификатов доступна в шапке списка.
- Обновлены OkHttp 4.12.1 и совместимый комплект сборки Gradle 8.14.7 / Kotlin 2.2.20 / Android Gradle Plugin 8.10.1 / Hilt 2.57.1.

## Bot4VPS Mobile 1.5.0

- Источник APK и метаданных перенесён в отдельный репозиторий Bot4VPS-Mobile. Новая сборка с тем же именем версии может обновляться при большем versionCode.

- Привязка телефона по QR и вход по его ключу без повторного Web-логина. Подключение по HTTPS к локальному IP без домена.
- При запуске виден адрес панели; «Изменить адрес» и «Подключиться к другой панели» доступны сразу. Через 10 секунд без ответа появляется подсказка о сети, VPN, адресе и порте. Сетевая ошибка не удаляет привязку.
- Просмотр мастер-ключа через PIN-код или биометрию; без защиты приложения — через пароль и второй фактор. Ключ скрывается при сворачивании и через 30 секунд.
- Автоблокировка после 30 секунд в фоне. Тема приложения сохраняется на телефоне отдельно от Web.
- Пинг серверов на «Обзоре», общий экран проверок пинга и SSL-сертификатов с сохранением результатов.
- SSH-терминал сохраняет соединение и вывод до пяти минут при уходе с экрана; нижние вкладки скрыты.
- Очистка журнала событий и истории задач вынесена в шапки экранов; переход между ними занимает всю ширину и содержит подсказку.

## Установка

С версии 1.6.0 обновление устанавливается поверх приложения с сохранением данных.
Для перехода с 1.1.3 требуется переустановка из-за смены подписи: сохраните
доступ к веб-панели и после установки 1.8.0 заново привяжите телефон.
Данные серверов в Bot4VPS сохраняются.
