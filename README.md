# Bot4VPS Mobile

**Bot4VPS Mobile** — официальное нативное Android-приложение для удалённого управления серверами и роутерами OpenWrt через Bot4VPS.

Приложение предоставляет основные возможности Bot4VPS на мобильном устройстве: мониторинг серверов и шлюзов, управление службами, выполнение команд, работу с файлами, резервное копирование и контроль безопасности.

Подключение к серверной части осуществляется через отдельный HTTPS Mobile API. После однократной привязки устройства приложение автоматически аутентифицируется при последующих подключениях.

В приложение также встроен Authenticator для хранения и генерации TOTP-кодов Bot4VPS и сторонних сервисов. Он работает независимо от сети, серверной части и мобильного подключения.

## Часть проекта Bot4VPS

Bot4VPS Mobile — официальный мобильный компонент основного проекта [Bot4VPS](https://github.com/crashdmd/Bot4VPS).

Серверная часть и мобильное приложение разрабатываются в отдельных репозиториях, имеют независимые циклы выпуска обновлений и взаимодействуют через общие API и ядро Bot4VPS.

- **Основной проект:** [Bot4VPS Server](https://github.com/crashdmd/Bot4VPS)
- **Мобильное приложение:** Bot4VPS Mobile (текущий репозиторий)

**Текущая версия:** [2.1.0](CHANGELOG.md)\
**Платформа:** Android 8.0 и новее\
**Минимальные требования:** Bot4VPS 7.5 с актуальными исправлениями API\
**Рекомендуемая версия сервера:** Bot4VPS 7.7.0 или новее для доступа ко всем возможностям приложения.

## Возможности

### Мониторинг и управление

- Общий обзор состояния серверов, графики нагрузки и TCP-проверка доступности.
- Мониторинг и управление шлюзами OpenWrt.
- Графики сетевой активности WAN и LAN с периодом по умолчанию 15 минут.
- Просмотр активных сетевых сеансов шлюза с фильтрацией по устройствам, назначениям и маршрутам.
- Управление серверами, группами и настройками мониторинга.
- Просмотр событий, истории задач и аудита.
- Контроль доступности серверов и сроков действия SSL-сертификатов.

### Управление сервисами

- Встроенный браузер для доступа к веб-интерфейсам сервисов и LuCI.
- Управление DHCP-арендами OpenWrt: просмотр текущих и статических адресов, закрепление IPv4, изменение и удаление резерваций с подтверждением действий.
- Управление Docker, WireGuard и 3x-ui.
- Работа с файлами и запуск скриптов.
- SSH-терминал с дополнительными клавишами, включая Ctrl.

### Резервное копирование

- Создание и управление резервными копиями.
- Восстановление данных с предварительным просмотром плана операций.

### Настройки и уведомления

- Управление группами серверов и их локальной видимостью в приложении.
- Получение push-уведомлений непосредственно на телефон независимо от настроек доставки Telegram.
- Просмотр уведомлений поверх текущего экрана и переход к полной истории событий.
- Независимая настройка темы приложения с сохранением выбора на устройстве.

### Authenticator и безопасность

- Генерация TOTP-кодов для Bot4VPS и сторонних сервисов.
- Добавление аккаунтов через QR-код или вручную, поиск по сохранённым записям.
- Доступ к локальным кодам без подключения к интернету и серверной части Bot4VPS.
- QR-вход в Web-панель и подтверждение чувствительных операций с помощью основного привязанного устройства.
- Управление подключёнными телефонами и получение уведомлений о запросах безопасности.

### Подключения

- Поддержка нескольких установок Bot4VPS с возможностью переключения между ними.
- Добавление и изменение адреса Mobile API через QR-код или вручную.
- Сохранение настроек подключений при переключении между панелями.
- Уведомления об отзыве доступа и возможность выбрать другое доступное подключение.

## Подключение и установка

Для подключения мобильного приложения необходима работающая установка Bot4VPS с настроенным Mobile API.

1. Откройте Web-панель Bot4VPS.
2. Перейдите в **Настройки → Мобильное приложение**.
3. Скачайте APK и настройте подключение.
4. Создайте QR-код и отсканируйте его в мобильном приложении для привязки устройства.

APK можно скачать непосредственно из Web-панели или через настроенного Telegram-бота.

Для работы с активными сетевыми сеансами и управлением DHCP-арендами предварительно обновите интеграцию во вкладке «Доступ» соответствующего шлюза OpenWrt.

Локальный Authenticator доступен независимо от наличия подключения к серверу Bot4VPS.

Подробная инструкция: [Подключение и настройка Mobile API](docs/connection.md).

## Безопасность

Для мобильного приложения используется отдельный HTTPS Mobile API. Устройство привязывается к установке Bot4VPS с помощью QR-кода. При последующих подключениях приложение проверяет ключ устройства и выполняет автоматическую аутентификацию без использования Web-логина.

Дополнительная защита приложения включает:

- Локальный PIN-код из четырёх цифр.
- Биометрическую разблокировку средствами Android.
- Автоматическую блокировку после 30 секунд нахождения приложения в фоне.
- Защищённый просмотр мастер-ключа с подтверждением личности и криптографической подписью устройства.

При включённой локальной защите просмотр мастер-ключа подтверждается PIN-кодом или биометрией без использования Web-2FA. Если локальная защита отключена, требуется пароль администратора и TOTP либо код Telegram.

Мастер-ключ автоматически скрывается через 30 секунд, при закрытии окна просмотра или переходе приложения в фон.

Подробнее об архитектуре защиты, ключах устройства, мобильных сессиях и аудите: [Документация по безопасности](docs/security.md).

## Работа с SSH-терминалом

Встроенный SSH-терминал позволяет выполнять команды непосредственно с мобильного устройства. Для удобства работы предусмотрены дополнительные клавиши, включая Ctrl.

SSH-сессия сохраняется при переходе в другие разделы приложения или его сворачивании на срок до пяти минут. При возвращении к терминалу того же сервера можно продолжить работу с сохранением предыдущего вывода.

Кнопка завершения в шапке терминала немедленно закрывает текущую сессию. После истечения пяти минут создаётся новое подключение.

При потере сети или принудительном завершении процесса Android соединение может прерваться раньше.

## Обновления

Мобильное приложение и серверная часть Bot4VPS обновляются независимо друг от друга.

В разделе **Ещё → Настройки → Обновления** доступны:

- Проверка и установка обновлений серверной части Bot4VPS.
- Проверка наличия новых версий мобильного приложения и скачивание APK.
- Настройка автоматической проверки обновлений.

Метаданные обновлений и APK размещаются в каталоге `apk/` репозитория [Bot4VPS-Mobile](https://github.com/crashdmd/Bot4VPS-Mobile), ветка `main`.

Перед установкой приложение проверяет размер загруженного файла, контрольную сумму SHA-256, идентификатор пакета, версию и сертификат подписи. Окончательное подтверждение установки выполняет Android.

## Обновление установленного приложения

Версия **2.1.0** подписана прежним release-ключом и устанавливается поверх версии **2.0.5** без удаления приложения.

При обновлении сохраняются:

- Сохранённые подключения.
- Локальные настройки.
- PIN-код и параметры защиты.

## Переход с версии 1.1.3

Версия Mobile 1.1.3 несовместима с Bot4VPS 7.0. Для работы с этой версией серверной части необходимо установить Mobile 1.8.0 или новее.

При переходе с Mobile 1.1.3 требуется удалить старое приложение и установить новую версию, поскольку сертификат подписи был изменён.

Перед удалением убедитесь, что у вас есть доступ к Web-панели Bot4VPS: после установки потребуется повторная привязка устройства.

Локальные настройки, PIN-код и существующая привязка могут быть потеряны. Данные и настройки серверов на стороне Bot4VPS при этом сохраняются.

Последующие обновления, подписанные тем же release-ключом, устанавливаются поверх текущей версии без переустановки.

### Быстрая сборка

Для самостоятельной сборки необходимы:

- JDK 17.
- Android SDK Platform 35.
- Android SDK Build Tools 35.0.0.

**Linux:**

```bash
chmod +x gradlew
./gradlew --no-daemon :app:assembleDebug
```

**Windows:**

```bat
gradlew.bat --no-daemon :app:assembleDebug
```

Готовый APK:

```text
app/build/outputs/apk/debug/app-debug.apk
```

Debug-сборка не требует release-ключа. Она подписывается отдельным сертификатом, поэтому для установки поверх официальной версии предварительно необходимо удалить установленное приложение.

Полная инструкция по сборке, подписанию и тестированию приведена в [руководстве разработчика](docs/development.md).
