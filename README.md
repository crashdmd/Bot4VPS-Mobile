# Bot4VPS Mobile

**Bot4VPS Mobile** — нативное Android-приложение для удалённого управления серверами через Bot4VPS. Оно предоставляет доступ к основным функциям сервиса с телефона: мониторингу, управлению службами, выполнению команд, работе с файлами и резервными копиями.

Приложение работает с уже установленным и настроенным Bot4VPS через отдельный HTTPS Mobile API. Первоначальная настройка сервиса выполняется через Web-панель. После однократной привязки телефона подключение выполняется автоматически, без повторного входа в Web-панель.

## Часть проекта Bot4VPS

**Bot4VPS Mobile** — официальное мобильное приложение для основного проекта [Bot4VPS](https://github.com/crashdmd/Bot4VPS).

Серверная часть и мобильное приложение развиваются в отдельных репозиториях, но используют общие API и ядро Bot4VPS и предназначены для совместной работы. Каждый компонент имеет собственный цикл разработки и выпуска обновлений.

- **Основной проект:** [Bot4VPS Server](https://github.com/crashdmd/Bot4VPS)
- **Мобильное приложение:** Bot4VPS Mobile (текущий репозиторий)

- **Текущая версия:** [1.6.0](CHANGELOG.md)
- **Платформа:** Android 8.0 и новее
- **Требования:** Bot4VPS 7.0 или новее

## Возможности

**Мониторинг и управление**
- Общий обзор состояния серверов с графиками и TCP-пингом.
- Управление серверами, группами и мониторингом.
- Просмотр событий, истории задач и аудита.
- Проверка доступности серверов и SSL-сертификатов.

**Управление сервисами**
- Управление Docker, WireGuard и 3x-ui.
- Работа с файлами и запуск скриптов.
- SSH-терминал с дополнительными клавишами.

**Резервное копирование**
- Создание и управление резервными копиями.
- Восстановление с предварительным просмотром плана операций.

**Настройки и уведомления**
- Управление группами и локальной видимостью.
- Уведомления непосредственно на телефон, независимо от настроек доставки Telegram.
- Отдельная настройка темы приложения, сохраняемая на устройстве.

## Подключение и установка

Для работы требуется настроенная установка Bot4VPS версии 7.0 или новее.

1. Откройте Web-панель Bot4VPS.
2. Перейдите в **Настройки → Мобильное приложение**.
3. Скачайте APK и настройте подключение.
4. Создайте QR-код и привяжите телефон через приложение.

APK можно скачать непосредственно из Web-панели или через настроенного Telegram-бота. Отключение Telegram не влияет на возможность скачивания из Web-панели.

[Инструкция по подключению](docs/connection.md) описывает настройку Mobile API, сетевой доступ, привязку и управление устройствами.

## Безопасность

Для подключения используется отдельный HTTPS Mobile API. Телефон привязывается к установке Bot4VPS с помощью QR-кода. При последующих подключениях приложение автоматически проверяет ключ устройства, без использования Web-логина.

Для дополнительной защиты предусмотрены:
- Локальный PIN-код из четырёх цифр.
- Биометрическая разблокировка средствами Android.
- Автоматическая блокировка после 30 секунд нахождения в фоне.
- Защищённый просмотр мастер-ключа с подтверждением личности и криптографической подписью телефона.

При включённой локальной защите просмотр мастер-ключа подтверждается PIN или биометрией, без Web-2FA. При выключенной защите используется пароль администратора и TOTP либо код Telegram.

Мастер-ключ автоматически скрывается через 30 секунд отображения, при закрытии окна или переходе приложения в фон.

[Подробнее о безопасности](docs/security.md) — устройство ключей, криптографическая аутентификация, мобильные сессии, защита данных и аудит.

## Работа с SSH-терминалом

В приложении предусмотрен SSH-терминал с дополнительными клавишами, включая Ctrl.

При переходе к другим разделам или сворачивании приложения SSH-сессия сохраняется до пяти минут. Возвращение к терминалу того же сервера позволяет продолжить работу с прежним выводом. Кнопка завершения в шапке терминала закрывает сессию немедленно.

После истечения пяти минут открывается новая сессия. При разрыве сети или завершении процесса Android прежнее соединение может закрыться раньше.

## Обновления

Приложение и серверная часть Bot4VPS обновляются независимо друг от друга.

В разделе **Ещё → Настройки → Обновления** доступны:
- Обновление серверной части Bot4VPS.
- Проверка и скачивание новых версий мобильного приложения.

Автоматическую проверку обновлений можно включить отдельно.

Метаданные и APK загружаются из каталога `apk/` репозитория [Bot4VPS-Mobile](https://github.com/crashdmd/Bot4VPS-Mobile), ветка `main`. Перед установкой приложение проверяет размер файла, SHA-256, пакет, версию и сертификат подписи. Окончательное подтверждение установки выполняет Android.

## Переход с версии 1.1.3

Mobile 1.1.3 не подключается к Bot4VPS 7.0. Для работы с этой версией панели установите Mobile 1.6.0. При переходе с Mobile 1.1.3 требуется удалить старое приложение и установить новую версию: сертификат подписи был изменён.

Перед удалением убедитесь, что у вас сохранён доступ к Web-панели, поскольку потребуется повторная привязка телефона.

Локальные настройки, PIN-код и привязка могут быть потеряны. Данные и настройки серверов на стороне Bot4VPS сохраняются.

Последующие обновления, подписанные тем же release-ключом, устанавливаются поверх текущей версии без переустановки.

### Быстрая сборка

Для самостоятельной сборки необходимы JDK 17, Android SDK Platform 35 и Build Tools 35.0.0.

```bash
chmod +x gradlew
./gradlew --no-daemon :app:assembleDebug
```

В Windows:

```bat
gradlew.bat --no-daemon :app:assembleDebug
```

Готовый APK:

```text
app/build/outputs/apk/debug/app-debug.apk
```

Debug-сборка не требует release-ключа. Она имеет отдельную подпись, поэтому для установки поверх официальной версии потребуется предварительно удалить её.

Полная инструкция по сборке, подписанию и тестированию приведена в [руководстве разработчика](docs/development.md).
